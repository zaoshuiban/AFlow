# 实验 A：生成、验证与预实验冻结协议

用户授权：完成生成、验证和预实验；正式评测稍后。本轮不生成正式测试集，不运行正式评测，不修改生产算子库。

## 研究问题

固定模型、通用 Python 权限及资源上限，比较原始求解、额外反思、冻结生成算子。程序权限相同，避免将增加工具权限误报为算子收益。该实现是隔离的结构化 Agent 预实验，不能直接称为原始 AFlow 完整图的复现。

## 冻结条件

- 任务：受限数字素数精确枚举。结构化 JSON 题面，明确数字集合、长度、可重复规则、闭区间与前导零规则。
- 模型：沿用本地 `deepseek-v4-flash` 别名，实际模型返回值保存到账本；官方 DeepSeek 端点，thinking disabled，temperature=0。
- 候选最多 2 个；生成器只见任务规格及 30 道开发题。禁止传入旧专项源码、验证题或预实验题。
- 30 道开发题、60 道随机验证题、6 道显式边界题。小规模验证答案由独立的数字扫描/试除实现与 SymPy 穷举实现交叉核对。另加 3 道无效输入拒绝测试。
- 跨开发、随机验证、预实验按数字集合、长度、重复规则隔离；不只换区间或措辞。
- 每个候选须通过全部 99 个执行检查。通过者按验证总墙钟时间选择一名，平局取编号小者。此处是预注册工程选择规则，不是算法优越性证明。
- 30 道预实验题，三个难度参数档各 10 题，每组一次，共 90 次作答；三个组随机交错执行。
- 每题各组最多 4 次模型调用、合计 8192 生成 Token、4 次工具调用、10 秒累计工具墙钟时间、180 秒总执行预算。工具墙钟限制比同量 CPU 限制更保守；每个独立进程另有 5 秒 CPU 限制和 RSS 监控。
- 所有组均可提交 `solve(problem)` 给同一白名单执行器。算子组增加 `operator` 动作，运行同一冻结代码；同样计一次工具调用。
- 反思组首个答案仅作草稿，必须在共同预算内再次检查并提交最终答案；不获参考答案或正确性反馈。
- 每次 API 请求保存原文、返回模型、finish_reason、用量、耗时；密钥只从本地配置读取，不写入结果。最终预实验使用原生 function tools，代码工具和最终答案都通过类型化接口提交，不依赖文本中嵌套的动作 JSON。
- API 自动重试为零；未知状态不偷偷重发。预算按高峰未命中缓存的输入 ¥2/M、输出 ¥8/M 保守核算；请求发出前预留，未知用量保留预留额。最终版本最多 ¥18.50、360 个请求，另预留 ¥1.50 覆盖先前接口调试运行，全轮最多 ¥20。
- 正式统计门槛在后续正式评测使用；本轮只做描述性汇总，不挑选新候选、不根据预实验结果改提示词。

## 接口修正与历史记录

1. `results/experiment_a_pilot_20261014/`：首轮两次生成。任务输入为 JSON 字符串，但继承执行器未允许 `json`，两个候选均导入被拒绝，未进入数学验证。原记录保留。
2. `results/experiment_a_pilot_20261014_v2/`：为三组统一增加标准 JSON 解析，重新冻结。候选 1 未通过数学验证，候选 2 通过全部 99 项检查。文本动作 JSON 的接口冒烟运行中出现大量 JSON 格式错误，运行主动中断：18 次完成观察、1 次请求中断用量未知。这批结果不能作为能力比较证据。
3. `results/experiment_a_pilot_20261014_v3/`：原生 API 工具接口冒烟成功，但算子可用组未实际调用算子，且各组反复在代码顶层打印/执行样例导致额外调用。22 次完成观察后主动中断，保留一条中断用量未知请求。此批用于定义干预和接口规则，不作为最终能力证据。
4. `results/experiment_a_pilot_20261014_v4/`：复用 v2 的同一份候选 2，未再次生成或编辑算法。固定算子组首次调用 operator；三组都明确只提交函数定义、由运行器调用并捕获返回值，不打印或自行执行样例。生成请求来源、原选择和候选哈希均冻结。新的 30 题排除前两版整个预实验池的参数题族；开发和验证样本保持不变。最终结果只引用本版本，早期调试费用计入累计账本。

此调整依据接口错误和干预没有实际发生，而非根据正确率挑选算子或难度；仍需在最终报告中明确披露。原始四版记录都保留，不覆盖历史响应。

## 免费实现验证

`tests/test_experiment_a_pilot.py` 的 6 项测试覆盖：参考交叉核对与分组隔离、真实受限执行、权限拒绝、强制反思、算子调用证据和调用预算。测试通过后冻结源码，再开始真实调用。

## 解释边界

随机种子产生的参数档不代表已校准的实际难度。若三组都近乎满分，应报告没有足够能力区分空间；若多为基础设施错误，应报告预实验不可靠。单次 30 题不能支持稳定能力增益的正式结论。运行器是白名单数学执行器，不是通用恶意代码强安全沙箱。
