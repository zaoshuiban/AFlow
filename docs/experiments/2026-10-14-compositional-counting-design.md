# Reflection 修复与组合约束计数开发校准

用户已明确指定三个阶段。本次落实阶段 1、2，构建并封存阶段 3 的 240 题测试池，但不读取测试结果、不生成新算子、不运行正式评测。继续沿用本地 DeepSeek Flash 配置、共享 Python 权限、4 次调用/8192 累计生成 Token/180 秒/10 秒累计工具墙钟预算。新增调用总预算上限 ¥20，自动重试为零。

## 阶段 1

采用执行器强制预留最终提交调用，而不是只提示模型“记得提交”，也不将正确草稿自动升级为最终答案。所有组最后一轮只提供 submit 工具，其他轮最多用掉 7680 生成 Token，保留至少 512 Token 给最终提交。Reflection 从首次有效工具结果或草稿进入复核阶段，最后提交必须是模型真实返回的 submit；无答案时允许显式 null，计为弃答而非未交付。只用原素数任务的 3 道开发题，三组各一次验证，不重跑旧测试池。

## 阶段 2

完整任务规格固定提供给 Baseline、Reflection 和未来算子生成器：字母表 0..3、1 起始位置、全部约束同时成立、子串出现按所有起点计数（包括重叠）、精确整数输出。约束类别为：符号恰好次数、相邻不同、元素和取模、禁止子串、子串恰好次数、位置奇偶禁用符号、首尾不同。

难度仅按约束类别数：Easy 1–2，Medium 3–4，Hard 5–7。每层 30 道开发题，各长度规模 10 道；规模区间分别为 8–12、16–24、28–36，对所有复杂度层相同。先冻结全部开发题，再运行两组一次，共 180 次作答。正确率区间仅作描述，不作为保留/删除题目的条件。

独立参考实现采用位置推进的精确 DP，状态只跟踪实际需要的符号次数、模余数、模式计数、后缀、首字符。小规模暴力实现直接枚举完整序列并逐项判约束，不复用 DP 转移。覆盖全部类别、重叠子串、无解和边界情况；验证不通过则不发 API 请求。

工具执行器支持精确大整数以及 Python 常见计数容器（包括 bytearray），移除原素数执行器 128 bit 返回值限制。文件、网络、进程和动态代码权限仍不开放；三组工具完全相同。

## 正式测试封存

独立种子生成 Easy/Medium/Hard 各 60 题，外加 60 OOD（30 长度外推、30 预先声明的组合外推）。组合外推使用接口已定义但从开发组合池排除的约束子集。正式题与参考答案保存在独立 sealed 目录，仅公开哈希及计数；开发校准入口不提供加载该目录的功能，正式执行另需后续授权。封存是本地程序隔离和哈希承诺，不冒充外部保密公证。

测试题不用于生成、修复、选择任何算子，参考求解器源码不放入模型上下文。若开发校准后需改变任务生成规则或执行预算，保留本版封存池并建立新的完整实验版本，不能从已封存测试池筛题。

## 结果解释

分别报告最终交付率、数学正确率、资源失败、工具错误、网络错误、复核是否实际发生、各复杂度×规模格的结果及成本。若开发集仍接近满分，直接报告无足够错误空间；若大多失败，检查参考状态规模、工具限制和模型建模错误。不得为达到理想正确率隐藏或替换样本。
