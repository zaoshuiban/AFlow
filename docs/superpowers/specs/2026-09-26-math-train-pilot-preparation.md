用户已要求准备独立训练 JSONL、核验评分器依赖，真实试跑由用户自行启动。本次不发出任何模型生成请求。

1. 固定 EleutherAI/hendrycks_math 的提交版本，核验七学科 train 合计 7,500 条、test 合计 5,000 条。作者当前链接的另一镜像把 12,500 条混入一个 train 标签，不采用该标签作为划分依据。
2. 保存原始分片与文件哈希；转换时保留题面/解答、来源分片与行号。只将原始 train 候选写入最终文件。
3. 全部源 test 只做重复检测；排除与本地 test/validate 及旧实验 JSON/JSONL/CSV 中任务字段的重叠。精确规范化与保守的 LaTeX 排版规范化均记录。未结构化文本与人工使用历史不能据此证明完全未见。
4. 在补装 ANTLR 前后分别保存评分检查结果；只在项目 .venv 安装 SymPy 1.14 对应的 4.11 系列运行时和 Parquet 转换依赖。若发现评分行为错误，明确记录修复及版本变化，不重算旧正式实验。
5. 验证、保留环境和版本快照，再 prepare 一个 160 题的独立运行目录（40/40/40/40），不调用 run。给用户启动、状态和续跑指令。
6. 固定请求预算和输出上限；小规模连通性试跑统一显式关闭 DeepSeek 思考模式，输出截断和空答案记作执行异常并保留已报告用量。记录当前配置中的 Flash 旧名称实际为新版兼容别名，不与旧版本实验混用。没有模型 API 实测，因此不能保证账户余额和远端接口一定可用。

验收：数据来源/排除审计可复查；评分器正负例和项目回归测试通过；prepare 完成且请求数为零；用户可用一条 run 命令开始付费试跑。
