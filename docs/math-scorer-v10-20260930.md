# MATH 评分器覆盖修补与离线审计

## 已确认范围

采用有限规则修补、正反例测试、保存回答的离线复评。没有引入大模型裁判，没有新增 API 请求，没有降低机制门槛，也没有更改已有算子或冻结实验。

评分器版本从 math_equivalence_v9 升为 math_equivalence_v10：

- 只有题面含完整显式选项时，才将 `(A)` 与 `A` 解析为选项内容。
- 识别数值金额前缀 `\$`，保留金额数值；不任意删除表达式中的美元符号。
- 将末尾 `\text{gallons}` / `\mathrm{gallons}` 纳入已有单位省略规则。这不是单位换算器。
- 统一单字符下标的花括号写法，不删除进制下标。
- 提取具有明确终止边界的单字符 `\boxed 2`；不把 `\boxed 12` 或 `\boxed 2+3` 截断成 1 或 2。
- 无序答案集合支持完整文本包装，保留坐标顺序和集合元素重复次数；带规范千分位的标量不拆成集合。

## 验证与边界

使用 unittest 执行全套测试，另运行评分器依赖与 34 项探针审计。新增正反例覆盖金额错误、不同进制、遗漏进制、错误集合、坐标顺序、数学变量大小写与不明确的 boxed 写法。

这是当前发现的六类格式覆盖修补，不代表所有数学等价判定问题均已解决。原评分器的数值容差、广义文本大小写判断、单位换算和自由自然语言答案仍需独立评估。剩余四道稳定失败题含 Asymptote 图形描述；应先审计图形输入、真实解题错误与评分歧义，再决定后续发现实验，不应直接将它们视为共同能力缺口。

新实验应重新准备目录，冻结 v10 评分器及代码哈希；不要修改旧 manifest 或用新评分器续跑旧归档实验。
